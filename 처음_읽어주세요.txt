아이폰 건강 식단 앱 사용 안내

1. 이 폴더 안의 파일 5개(index.html, manifest.webmanifest, service-worker.js, icon-180.png, icon-192.png, icon-512.png)를 같은 위치에 웹사이트로 올려야 합니다.
2. 가장 쉬운 무료 배포 방법: GitHub Pages. 저장소에 이 파일을 올리고 Settings > Pages에서 main 브랜치의 / (root)를 게시합니다.
3. 발급된 https://주소를 본인과 여자친구의 아이폰에서 각각 Safari로 엽니다.
4. 공유 메뉴 > 홈 화면에 추가 > 웹 앱으로 열기 > 추가를 선택합니다.

주의: 무료 GitHub Pages로 게시한 웹사이트와 코드 자체는 공개됩니다. 이름/키/몸무게 같은 개인 정보는 소스코드에 직접 넣지 마세요. 이 프로그램은 현재 사용자 계정, 서버 저장, 두 기기 간 자동 동기화 기능이 없습니다.
